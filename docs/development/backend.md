# Backend development

::: info
Make sure you have `.env` file with needed [environment variables](/deployment/env-vars.md)
:::

## Install [Vercel CLI](https://vercel.com/docs/cli)
```
npm i -g vercel

```

## Run the application and serverless functions locally
```
vercel dev
```

For more info about `vercel dev` follow this [link](https://vercel.com/docs/cli/dev).
